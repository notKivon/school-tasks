Cards. The class chip sits on its own row across the top of the card; the checkbox and the title share the line below, and the title runs the full width of the card. Delete appears on hover at the right end of the chip row (shown on the Calc test card, with its red hover). On a card with no chip it sits in the top-right corner, and only the first line of the title steps around it.

Editing. Clicking a title swaps it for a field set in exactly the same size and position, so the card doesn't grow or jump. Enter saves, Esc cancels.

Adding. The add-task field has no helper text; the placeholder shows the one habit worth knowing (start with a class). Enter adds the task and opens a fresh field for the next one; Esc closes it.

Columns. All five columns run the full height of the window. When a column has more cards than fit, its list scrolls inside the column and Add task stays in view. The count beside each title is active cards only.

Dragging. The lifted card floats above the board while the target column shows where it will land and what its new date will be. The dashed outline left in Today / Due is the exact size of the card that left, so the column doesn't jump.

No label. “Calc trick for limits” is stored as \Calc trick for limits: the backslash keeps it unlabelled, so it gets a gray edge and no chip, and in the three day columns it sorts with the unlabelled cards.

Touch. No hover on phones, so the trash icon stays visible in a quiet gray. Drag starts on a long press (250ms) so the column still scrolls sideways under your thumb.

Tabs. Tap a tab to snap to that column (try it on the left phone). The active tab follows when you swipe and the strip scrolls to keep it fully in view. When more tabs sit off the edge, the strip fades out on that side to show it scrolls. Short tab names are for the strip only; the column header keeps the full name.

Sheets. Classes, Calendar and the account menu open as a bottom sheet with a grabber, over a dimmed board. Swipe down or tap outside to close.

Inputs. Add-task and title inputs use 16px on phones so iOS doesn't zoom.

Line height 1.45 for body, 1.25 for display. Nothing a user reads on the board is smaller than 13px, except chips and badges at 12px semibold. Source Sans 3 replaces Atkinson Hyperlegible Next because Atkinson's zero is always slashed (it has no plain-zero alternate), which made every date read like code; Source Sans 3 has a plain zero and tabular figures by default. Fontsource packages: @fontsource-variable/fraunces, @fontsource-variable/source-sans-3, @fontsource/atkinson-hyperlegible-mono (400 only; its slashed zero is fine for code and the calendar link).
